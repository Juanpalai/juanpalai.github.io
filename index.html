AirSim ROS Wrapper for Autoware

A closed loop between a high-fidelity vehicle simulator and the full Autoware autonomy stack.

Problem
Autonomy changes need to face realistic sensors and physics before they can be trusted on a real vehicle.
Built
Modified ROS packages that feed AirSim's simulated LiDAR, camera, and IMU streams into Autoware, so the complete autonomy stack runs against a simulated vehicle.
Stack
  • AirSim
  • ROS
  • Autoware
  • C++
Result
Autoware runs end-to-end against simulated sensors, from perception through planning to the vehicle commands that drive the simulated car. [result pending]

RandomNav2Controller

A ROS 2 package that keeps Nav2 driving toward goals nobody hand-picked.

Problem
Testing a navigation stack against one hand-picked route says little about how it behaves under goals nobody chose.
Built
A ROS 2 package that generates random goals and drives a TurtleBot3 toward them through the Nav2 stack in a simulated environment.
Stack
  • ROS 2
  • Nav2
  • TurtleBot3
Result
The robot keeps navigating toward goals it has never seen, exercising Nav2's planning and control servers in a continuous loop. [result pending]
